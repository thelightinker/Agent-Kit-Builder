## Hướng dẫn Lưu mẫu mới
Khi một bộ Kit hoàn thành chạy `/validate-kit` và đạt 5/5 ⭐, kích hoạt workflow `/remember-kit` để:
1. Đóng gói bản thiết kế mẫu vào thư mục này.
2. Thêm liên kết vào bảng danh mục trên.
