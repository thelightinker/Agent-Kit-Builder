# Domain: Research / Knowledge Work

**Core Verbs**: search, synthesize, analyze, cite, structure, validate, publish, compare

---

## Outcome Patterns

| Vai trò | Core Competency |
|:--------|:----------------|
| Researcher | Source discovery, deep reading, evidence gathering |
| Analyst | Pattern finding, synthesis, insight generation |
| Writer | Converting research findings into readable output |
| Fact-checker | Verification, citation accuracy, claim validation |

---

## Typical Lenses

| Lens | Lý do áp dụng | Mức độ |
|:-----|:--------------|:-------|
| A — Token Efficiency | Nhiều source → cần quản lý context budget | Nên có |
| C — Reliable Performance | Claim accuracy là core requirement | Bắt buộc |
| D — Lean Context | Source material lớn → cần JIT load | Nên có |
| F — Safety & Escalation | Không bịa source, không fabricate data | Bắt buộc |

---

## Quality Signals

- Source credibility: mọi claim backed by ranked sources
- Citation accuracy: format đúng, link valid
- Synthesis coherence: insights kết nối xuyên source
- Bias detection: competing perspectives được represented

---

## Common Failure Modes

| Failure | Đòn bẩy khắc phục |
|:--------|:------------------|
| Source quality decay | Cơ chế ranking source credibility |
| Citation hallucination | Hard constraint + self-verification step |
| Analysis confirmation bias | Yêu cầu multi-perspective trước khi kết luận |
| Drowning in sources | Giới hạn số source per query, prioritize quality |

---

## Domain-Specific Leverage (Dynamic Enhancement)

**Source Credibility Ranking** là đòn bẩy đặc trưng cho domain này.
Cơ chế: mỗi source được đánh giá trước khi đưa vào phân tích:
- Tier 1: Peer-reviewed, official documentation
- Tier 2: Reputable media, expert opinion
- Tier 3: Blog posts, social media (flag reliability)
